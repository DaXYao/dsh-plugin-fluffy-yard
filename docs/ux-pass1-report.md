## 需求细化与实现

### UX-1 舞台宽高：可发现、可恢复、可拖拽

**痛点**：宽高范围不可知；宽高同时设很小时调参台被裁剪不可见，失去恢复手段。

**细化与实现**：
1. **根因修复**：调参台面板与齿轮原本挂在舞台 `.py-stage` 内部，被舞台 `overflow: hidden` 裁剪——移到**容器层**（任何舞台尺寸下都完整可见可点，实测 120×90 极小舞台下齿轮与面板完好展开）。
2. **拖角手柄**：舞台右下角新增 18px 手柄（`.py-stage-resize`），按住拖动实时改宽高，同步滑条/数值框并自动钳制范围；`setPointerCapture` 加防御。
3. **范围可发现**：调参台新增提示行「范围：宽 80–1400 · 高 80–800 · 拖舞台右下角可调」，数值框 title 同步。
4. 「恢复跟随面板」保留（一键回 100%）。

### UX-2 面板互斥

**痛点**：调参台与右上浮层面板可同时打开，互相遮挡。

**实现**：双向互斥——展开调参台 → 自动关闭右上浮层面板（`DebugHooks.onOpen` → `panels.closeAll()`）；展开任一浮层面板 → 自动收起调参台（`PanelsOptions.onPanelOpen` → `debugHandle.setVisible(false)`）。工具条（📊📖📷🏆🌓🌧️⚙️）与浮层面板同样移到容器层。

### UX-3 自定义在场上限 + 到访间隔下限 30 秒

**细化与实现**：
1. **在场上限**：`Settings.maxPets` 加性字段（1–10，缺省 5，随存档持久化，不升 schemaVersion）。`spawn.ts` 新增 `maxPetsOf(yard)`，到访淘汰/满员全锁定暂停按其判定；设置面板新增「在场上限（只）」输入（应用即存 + toast）；HUD 显示 `在场 N/上限`；「演示存档」按当前上限生成。超上限的既有宠物随自然到访淘汰回落（设计行为）。
2. **间隔下限 30 秒**：`SPAWN_INTERVAL_MIN_MIN` 10 → **0.5 分钟（= 30 秒）**；设置面板间隔输入改用**秒**单位（30–86400 秒，步进 30），内部仍以分钟存储（支持小数）；实测应用 30 秒后 HUD 倒计时 0:29。
   - 成就「五口之家」语义不变：需 ≥5 只全部锁定（上限调小后自然更难达成，属预期）。

### UX-4 下雨场景

**细化与实现**：P5 的雨为 10% 随机纯视觉层（难遇）。本轮加**天气按钮** 🌤️/🌧️（工具条）：点击切换雨天/晴天——雨天显示斜线雨幕覆盖层（纯视觉不影响交互），按钮图标/title/toast（「下雨了…」「雨停了」）跟随；偏好持久化（`dsh-plugin-pet/rain`）；无手动偏好时激活仍 10% 随机。

## 偏差与决策树使用记录

1. **core 修改说明**：maxPets 与间隔下限涉及 `core/types.ts`、`core/doc.ts`、`core/spawn.ts`、`config.ts`——既往阶段手册的"core 冻结"是阶段验收约束；本轮为用户直接需求（产品口径变更），按加性字段/缺省兜底方式最小侵入，既有测试零改动零回归。
2. **「五口之家」语义**：上限自定义后，flag 判定固定为「≥5 只全部锁定」（成就名/条件不变；上限 <5 时自然更难达成）。
3. **debug.ts 返回类型变更**：`() => void` → `DebugHandle { dispose, setVisible }`（互斥所需）；controller 同步。
4. **panels.ts 参数语义**：`mountPanels` 第一参从舞台改为容器（工具条/面板容器层化）。
