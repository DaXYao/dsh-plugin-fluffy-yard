# 「毛茸茸小院」— DeepSeek Harness 宠物插件需求文档

> 版本：v0.3（已确认核心决策，可进入开发）
> 工作代号：Furry Visitors（名字随意换）

---

## 1. 一句话概述

在你的插件面板里有一座小小的院子，每隔一段时间会有一只**独一无二**的小猫或小狗前来做客。它们在院子里蹦跶、打滚、打个盹；你可以锁定喜欢的宝贝让它常驻，给它拍立绘、和全院合影，并记录下你每一次前来看望它们的日子。

**特色机制**：面板可自由缩放，而宠物们对窗口大小会有真实的"反应"——窗口越挤，它们越热闹；当窗口只容得下一只时，一场争宠大战随即上演。

---

## 2. 核心玩法循环（用户视角）

1. 打开面板 → 院子里有 ≤5 只宠物正在活动，各自做着小动作。
2. 每隔 30 分钟（可配置），一只**全新长相**的宠物到场（入场动画 + 名字气泡）。
3. 若院子已满（5 只），到场时间最早的**未锁定宠物**会收拾行李告别离场。
4. 用户可以：
   - 摸一摸 / 看档案（放大查看特征）
   - 锁定心仪的宠物（常驻，不被新来客挤走）
   - 给宠物导出「档案卡」图片，或与全院合影
   - 查看「探望记录」：总次数、每次时间戳、连续探望天数
   - **拖拽缩放面板窗口**，观察宠物们从悠闲到拥挤的百态，以及热情分子们的争宠大战
5. 离开的宠物进入**图鉴**，偶尔回忆，甚至寄来一张明信片。

## 3. 功能需求

### 3.1 场景与到访机制

| 项目 | 规则 |
|---|---|
| 场景 | webview 中的一个固定小场景（草地/院子），面板可自由缩放 |
| 到访间隔 | 默认 **30 分钟**一只，设置中可调（10 分钟 ~ 24 小时） |
| 数量上限 | 在场最多 **5 只** |
| 淘汰规则 | 新宠物到场且已满 5 只时，**到场时间最早的未锁定宠物**离场（注意：不是"最早的宠物"，而是"最早的未锁定宠物"） |
| 离场表现 | 告别动画（挥手 → 走向屏幕边缘渐隐），随后进入图鉴 |
| 全锁定时 | 5 只全部被锁定则**暂停新宠物到访**，UI 提示"小院已满，住满都是你锁定的宝贝"；解锁任意一只后恢复 |
| 离线补算 | 打开时按离线时长最多补 1 只（"它在门口等你很久啦"），其余不补，防止离线刷宠 |

### 3.2 外观与唯一性

**"不重复"的定义**：**特征组合唯一**——任意两只宠物的完整特征组合不同。

- **L1 场内唯一**：当前在场的 5 只互不重复。
- **L2 历史唯一（已确认）**：与图鉴中所有出现过的宠物都不重复。组合空间估算：2 物种 × 3 体型 × 4 耳型 × 10 毛色 × 5 花纹 × 3 尾巴 × 4 眼色 ≈ **14,400 种**，足够长期使用。
- **耗尽策略**：组合用尽后进入「轮回」——允许复用组合，但附加特殊标记（如星星胎记 + "二世"称号），图鉴中可区分。

特征维度表（初版，具体数值开发期调参）：

| 维度 | 可选值（示例） |
|---|---|
| 物种 | 猫 / 狗（各 50% 纯随机） |
| 体型 | 小巧 / 圆润 / 大只 |
| 耳朵形状 | 立耳 / 折耳 / 垂耳 / 精灵耳 |
| 毛色 | 白、黑、橘、灰、奶咖、奶牛、三花、蓝灰、奶油、烟棕… |
| 花纹 | 纯色 / 斑点 / 虎斑条纹 / 渐层 / 白手套（爪尖白） |
| 尾巴 | 短尾 / 长尾 / 蓬松大尾巴 / 卷尾 |
| 眼睛颜色 | 琥珀 / 湖蓝 / 翠绿 / 异瞳 |
| 配饰（低概率） | 小围巾 / 铃铛 / 蝴蝶结 / 无 |

生成算法要点：

- 使用**带种子的随机数**（seed = 宠物 id）：保证同一只宠物在任何设备上长相永远可复现，图鉴回看不失效。
- 性格（热情度，见 §3.7）同样由 id 种子推导，与长相一起生成、终生不变。
- 生成时查询"已用组合"集合，冲突则重摇。

### 3.3 动作系统

动作随机触发、彼此独立，宠物之间不同步（更有"各忙各的"生活感）。

- **基础动作**：待机（呼吸起伏）、左右踱步、跳跃、打滚、坐下、打盹（冒 Z z z）
- **卖萌动作**：转圈圈、追自己尾巴、伸懒腰、舔毛、歪头看镜头
- **入场动画**：从屏幕边缘小跑入场，头顶弹出名字气泡："你好呀，我是汤圆！"
- **离场动画**：原地挥手 → 走向边缘渐隐（P3 彩蛋：背着一个比自己还大的小行李包）
- **宠物间互动（P2）**：两只宠物偶尔互相追逐、贴贴、玩同一个球

### 3.4 锁定机制

- 点击宠物 → 弹出互动菜单 → 「锁定 / 解锁」。
- 锁定后：宠物头顶常驻**小锁 / 爱心徽章**；不再参与淘汰。
- 被解锁后**按原到场时间重新排队**参与淘汰（保持公平，无"重置保护期"）。
- 锁定数量不设硬性上限（可全锁 5 只，代价是暂停新访客）。
- **锁定的额外福利**：争宠模式中上台时间加倍（见 §3.7）。

### 3.5 拍照与导出

- **单只导出（档案卡）**：一张"宠物档案卡"——立绘 + 名字 + 编号（如 №0421）+ 特征标签（"垂耳 · 奶牛色 · 蓬松尾"）+ 性格（热情/淡定/高冷）+ 相遇日期。导出 PNG。
  - 档案卡始终使用**完整立绘离屏渲染**，不受当前窗口大小/档位影响。
- **全院合影**：整个场景截图，自动盖水印角标：**日期 + "第 N 次探望"**——把统计数据变成合影的一部分。
  - 合影时无视当前档位：全员（含边缘探头者）被临时召回，**挤成一团**完成"挤挤更亲密"构图，拍完各回各位。
- 命名规则：宠物自动获得随机名字（见 4.1），用户可重命名。

### 3.6 统计与记录

| 指标 | 定义 |
|---|---|
| 总探望次数 | **每个自然日首次打开面板计 1 次**（已确认；另记"累计打开次数"作参考） |
| 探望日志 | 每次探望的时间戳列表（日期 + 时刻） |
| 连续探望天数 | streak + 历史最长纪录 |
| 相遇总数 | 历史上到访过的宠物总数 |
| 合影次数 | 累计导出合影张数 |

### 3.7 ★ 窗口缩放反应系统（争宠机制）

面板可自由缩放，宠物对可见空间的变化做出**分档行为 + 实时反应**。这是本插件的特色系统。

**容量模型**

- 每只宠物需要一个"舒适格位"（宽度约 140px，开发期调参）。
- 可见格位 = floor(场景宽度 ÷ 格位宽度)；按"可见格位 vs 在场宠物数"划分档位。

**热情度（争宠的入场券）**

争宠不是全员行为——每只宠物有自己的**热情度**，出生时由 id 种子随机决定（0–100，终生不变，与长相、名字同源可复现），并映射为三档性格：

| 性格 | 热情度 | 概率 | 行为倾向 |
|---|---|---|---|
| 热情 | ≥ 60 | 约 40% | **争宠的唯一发起者**：抢位、撞肩、顶替上台、上台臭美，样样来 |
| 淡定 | 20 ~ 59 | 约 40% | 从不主动争宠；被挤会退让，被点名照样配合上台；舞台空着且无人抢时，也可能慢悠悠踱上去趴着 |
| 高冷 | < 20 | 约 20% | 对舞台毫无兴趣，主动待在边缘背对镜头；被点名时慢吞吞挪上台，头顶"……" |

- 挤碰发生时，**不热情者会主动退让，热情者会顶回去**——被挤到边缘的天然多是不热情的家伙。
- **允许全场一只热情宠物都没有**：此时争宠整体停摆，进入「冷场模式」（见聚光灯规则）。
- 性格轻微影响日常动作偏好：热情者更爱蹦跳转圈，高冷更常趴着打盹、慢悠悠舔毛——性格是"人设"，不只存在于争宠时刻。
- 性格写入档案卡（§3.5），是收藏的一部分。

**分档行为**（按顺序判定）

| 档位 | 条件 | 宠物反应 |
|---|---|---|
| 宽裕 | 格位 ≥ 在场数 | 一切如常，各自散开活动 |
| 拥挤 | 格位 < 在场数，且格位 ≥ 3 | 宠物们靠拢站位；挤不下的**热情者**在屏幕边缘探头探脑、反复往里挤，偶尔与同伴"撞肩"互瞪；**淡定/高冷**被挤则大方让位，在边缘安静趴着看风景 |
| 狭小 | 格位 = 2 | 明显卡位：卡位优先被热情者占据并死守；边缘的热情者时不时发起冲刺抢位，不热情者只在两侧观望徘徊 |
| 聚光灯 | 格位 = 1 | 见下方「聚光灯规则」与「冷场模式」 |
| 极小 | 场景低于最小展示尺寸 | 只露出一对大眼睛从边缘窥视；或一只被压扁成 Q 弹的"宽扁"形变挤进来 |

**聚光灯规则**

- **争宠只发生在热情者之间**：热情的挑战者冲入撞飞现任，现任打滚出场（头顶"哇！"），新任上台昂首挺胸、双爪挥舞臭美；其余热情者在边缘露出耳朵/爪子/半张脸，伺机而动。
- 现任若是**淡定/高冷**（比如刚被点名上台），面对挑战者不还手，耸耸肩平静让位。
- 轮换节奏约每 15 秒一次；**锁定宠物上台时长加倍（30s）**并佩戴小皇冠徽章——锁定福利可视化。
- 全场只有一只热情者时，它偶尔会自己跳下台溜达一圈再杀个回马枪——独占舞台太无聊。
- **点名**：点击头像条上任意宠物头像，该宠物立刻上台顶替现任。点名**无视性格**——高冷也会来，只是慢吞吞地挪，头顶"……"。
- **冷场模式**：在场没有任何热情宠物时（5 只满员约 8% 概率，宠物越少越常见），争宠自动暂停——舞台空着，或被一只淡定的宠物占着打盹（占着舞台睡大觉，也没人来抢）；全员在边缘各自趴着、看云、发呆，偶尔接连传染打哈欠，首次进入时轻提示一次"今天大家都有点懒得营业……"。新到访的宠物中若有热情者，好戏立刻恢复。

**实时反应（拖拽缩放过程中）**

- 缩小跨越档位瞬间：**热情者**集体惊跳 + "！"气泡，**淡定**抬头看一眼，**高冷**只抖一下耳朵、眼睛都不睁——随即各自切换到对应档位行为。
- 放大跨越档位瞬间：热情者欢呼（转圈/小跳）冲回场景；不热情者溜达着慢慢晃回来。
- **矮窗彩蛋**：窗口高度过矮时，全员"躺平"（横向摊平的搞笑姿势），高度恢复后爬起来抖抖毛。

**交互保障（小窗口下如何操作看不见的宠物）**

- 场景边缘常驻一条**全家福头像条**：最多 5 个圆头像（锁定者带小锁角标）。
- 点头像 = 点名上台；点头像上的 ⋯ = 直接打开该宠物的互动菜单（锁定/重命名/导出档案卡），无需它当前可见。

## 4. 趣味性增强（按优先级）

### 4.1 P1 — 核心趣味（进 MVP）

1. **自动起名器**：从音节库随机组合（"汤圆、年糕、煤球、布丁、闪电、憨憨…"），猫狗各有风格池；用户可重命名。名字是情感连接的第一步。
2. **档案卡导出**（见 3.5，本身就是收藏品）。
3. **入离场动画**（见 3.3）——让"到来"和"告别"成为事件，而不是数值变化。
4. **争宠系统基础版**（见 3.7）：热情度简化为二档（热情/不热情）+ 拥挤档探头 + 聚光灯轮换；三档性格与冷场模式随 M2 全量上线。

> 注：稀有度系统已确认**不做**。

### 4.2 P2 — 进阶

1. **心情系统**：每只宠物有心情值（ZZZ → 平静 → 开心）。用户探望、合影会提升全院心情；心情越高，卖萌动作越频繁。给"常来看看"一个正反馈。心情高涨时，淡定宠物偶尔会短暂加入争宠（临时加演，不改变基础性格）。
2. **明信片**：离开的宠物在若干天后随机"寄回"一张明信片（一张小图 + 一句话："在新家的院子里晒太阳，很想念你 ——"），归档进图鉴。冲淡"宠物离开"的失落感。
3. **图鉴 / 相册**：所有相遇过的宠物一览（缩小立绘 + 名字 + 相遇/告别日期），点击回看完整档案卡。收集欲驱动长期使用。
4. **成就系统**（示例）：
   - 「初来乍到」第一次探望；「常客」连续探望 7 天；「铁粉」30 天
   - 「初次相遇」第 1 只；「缘分不浅」相遇 50 只；「万物图鉴」集齐所有耳型/毛色各一次
   - 「全家福」第一次合影；「摄影师」累计合影 20 张
   - 「此心安处」第一次锁定；「五口之家」锁定满 5 只
   - 「挤挤更亲密」在聚光灯模式下完成一次全员合影；「让让我嘛」亲眼见证一次争宠顶替；「今日冷淡」亲历一次冷场模式；「勉强营业」点名一只高冷宠物上台
5. **昼夜 / 天气场景**：按用户真实时间切换白天/黄昏/夜晚（夜晚宠物更容易打盹）；偶发晴天雨天河边——纯视觉彩蛋。

### 4.3 P3 — 锦上添花

1. 宠物间互动动画（追逐、贴贴、玩同一个球）（P6 实现）
2. 小礼物收藏架：宠物偶尔叼来一片叶子 / 瓶盖 / 小饼干，陈列在院子角落（待定）
3. 点击宠物的即时反馈（爱心粒子 + 开心动作）（P6 实现）
4. 音效（脚步、打滚的咕噜声，可全局静音）（待定）
5. **场景家具**（v0.5 新增）：后墙 + 窗户、沙发、小桌；宠物可换位置去家具处（P6 实现）
6. **吃喝系统**（v0.5 新增）：水碗（无限）与食盆（有份数，点击添食）；宠物周期性走去吃喝（P6 实现）
7. **昼夜手动切换**（v0.5 新增）：自动/白天/黄昏/夜晚循环按钮，与本地时钟自动模式并存（P6 实现）

## 5. 数据模型草案

```jsonc
{
  "pets": [                         // 在场宠物（≤5）
    {
      "id": "p_000042",             // 种子，决定长相、默认名字与热情度
      "name": "汤圆",               // 自动生成或用户重命名
      "species": "cat|dog",
      "traits": { "body": "...", "ears": "...", "fur": "...",
                  "pattern": "...", "tail": "...", "eyes": "...", "accessory": "..." },
      "arrivedAt": 1770000000000,   // 到场时间戳（决定淘汰顺序）
      "locked": false,
      "mood": 72                    // P2
    }
  ],
  "archive": [ ... ],               // 图鉴：已离开宠物（含告别时间、明信片）
  "stats": {
    "visitCount": 37,
    "visitLog": [ 1770000000000 ],
    "streak": 5, "longestStreak": 12,
    "metTotal": 61, "photosTaken": 9,
    "achievements": [ ... ]
  },
  "usedCombos": [ "cat|small|fold|white|solid|long|amber|-", ... ], // 历史唯一性
  "settings": { "spawnIntervalMin": 30 },
  "lastSpawnAt": 1770000000000
}
```

> 宠物 id 是唯一真相源：traits、默认名字、热情度均可由 seeded RNG 从 id 推导，持久化时只需存 id + 用户自定义字段（重命名、锁定等）。

## 6. 已确认决策（累计至 v0.3）

| # | 决策 |
|---|---|
| 1 | 插件形态：**webview**，面板可自由缩放 |
| 2 | **不做稀有度系统** |
| 3 | Harness 提供**本地存储**与**文件导出 API**（PNG 导出落盘可用） |
| 4 | "一次探望" = 每个自然日首次打开面板 |
| 5 | 全部锁定时暂停新访客（设置中可改为"锁定上限 4"模式，P3） |
| 6 | 到访间隔默认 30 分钟，可配置 |
| 7 | 唯一性采用历史唯一（L2）；组合耗尽进入"轮回" |
| 8 | 离线最多补 1 只；猫狗各 50% |
| 9 | 窗口缩放反应系统（争宠机制）列为核心特色，见 §3.7 |
| 10 | 争宠表现仅由**热情**宠物发起；热情度出生时随机决定（热情/淡定/高冷 ≈ 40%/40%/20%），**允许全场无热情宠物**（冷场模式） |
| 11 | 美术风格可选：几何简笔风（开发期占位形象）转正为长期可选风格；最终版猫狗美术以**并列风格**接入，用户在设置中切换（v0.4） |

**开发期调参项**（不阻塞开发，实现时微调）：格位像素宽度、聚光灯轮换时长、名字库内容、特征可选值数量、矮窗躺平阈值。

## 7. 技术实现要点

- **渲染：SVG 分层拼装**。每个特征维度是一个图层（耳型 × 毛色 × 花纹……），按 traits 组合叠加渲染。优点：素材体积小、组合自由、矢量缩放无损、导出 PNG 时可用 canvas 序列化。
- **缩放感知**：webview 内用 `ResizeObserver` 监听场景容器（比 `window.resize` 更可靠），按实时宽度计算可见格位 → 驱动分档行为状态机。拖拽过程中的档位跨越事件触发"惊跳/欢呼"即时反应。
- **形变动画**：压扁、探头、打滚等用 SVG transform + CSS transition 实现，无需额外素材。
- **时间驱动，而非定时器驱动**。插件面板经常被挂起/关闭，`setInterval` 不可靠。持久化 `lastSpawnAt`，每次面板激活时用 `now - lastSpawnAt` 反推应该发生几次到访，再补演动画。
- **Seeded RNG**：由宠物 id 决定全部特征与默认名字，保证可复现。
- **持久化**：单一 JSON 文档存全部状态（结构见 §5），使用 harness 本地存储 API。
- **导出**：SVG → 离屏 canvas 栅格化 → PNG，经 harness 文件导出 API 保存。
